앞으로 만드는 **모든** 연출(소환, 허브, 로스터, 스킨, 이벤트 포함)은 이 절을 따른다.

### 1-2. 타이포

- 서체는 `Galmuri11` 하나만. 한글 10px 미만 금지 (`MAINTENANCE.md` 규칙).
- 캡션 문법: `킥커(11px · letter-spacing .3em · 마젠타) + 본문(22px+ · 타자기 26ms/자)`.
  킥커는 영문 관측 어휘(OBSERVATION LOG / ANOMALY / CONTACT / PROLOGUE / STAGE n-n).
- 네임플레이트 문법: `작은 스테이지 라벨 → 좌우 골드 헤어라인(scaleX 0→1) → 대형 타이틀(44~48px + 골드 글로우)`.

### 1-3. 모션 어휘

- **픽셀은 스텝으로**: 등장·흔들림·컷인은 `steps(2~3)`. 매끄러운 ease는 링·페이드에만.
- **슬램**: `scale 2.1 → 0.92 → 1.05 → 1`, `cubic-bezier(.2,.85,.25,1.1)`, 0.5~0.6s.
- **충격 3종 세트**: 플래시(`#fff3d6`, 0.2s steps(2)) + 확장 링(0.55s, 골드/마젠타 2겹 엇박) + 흔들림(`shakeB` 0.45s steps(2)). 큰 사건에만, 한 장면 최대 2회.
- **수축 링**: `scale 1.5→0.5` 페이드, 1.2s — "관측당한다" 신호 전용.
- **레터박스**: 상하 6.5vh, 인/아웃 0.5s. 컷신·프롤로그·입장·승패에서만. UI 화면에는 금지.
- **파티클**: 골드 엠버 상승(380ms 주기), 방사 더스트 8~24개, 별똥별 확률 9%. 패배 화면에는 파티클 없음.
- **컷 전환**: 장면 간 하드컷 + 플래시 1프레임. 크로스페이드 금지(픽셀 아트가 뭉개진다).
- `prefers-reduced-motion: reduce`에서는 각 장면의 최종 정지 프레임만.

### 1-4. 서사 규칙 (기존 스펙 계승)

- 관측자(외부 존재)는 저대비 청록-잿빛, 전신·정면·이름 노출 금지, 골드 사용 금지.
- 승리는 "파괴"가 아니라 **"별빛 회수"** — 거상은 하얗게 타서 별빛으로 오른다.
- 패배는 처벌이 아니라 **"관측 중단"** — 조용히 어두워지고, 재도전 CTA만 골드.
