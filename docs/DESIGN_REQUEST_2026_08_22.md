## 1. 반영한 것 아홉

| 무엇                  | 이전                            | 이후                                     |
| --------------------- | ------------------------------- | ---------------------------------------- |
| 스테이지 기믹         | 36판 중 1판                     | **34판**, 일곱 종 전부                   |
| 별지기·거상 대사      | 2줄                             | **80줄** (별지기 48 · 거상 16 · 사건 10) |
| 효과음 음색           | 이름 14개가 표에 없어 같은 소리 | 전부 갈림, 별자리는 등급 다섯            |
| 기믹 아이콘           | 없음                            | **여덟**, 캔버스로 직접                  |
| 기믹 교습             | 없음                            | 처음 만나는 판에서 루나가 한 번          |
| 허브 지도의 기믹 이름 | 한 번도 안 보였다               | terrain 과 «합쳐» 보인다                 |
| 도는 방벽             | 조준 중 얼어붙어 안 보였다      | 돈다                                     |
| 가속·흐림 이펙트      | 일반 흩뿌리기                   | 위로 뻗음 / 아래로 가라앉음              |
| 반사 벽               | 배경에 묻힘                     | 그림자 + 명도 한 단                      |

### 설계에서 지킨 규칙 셋

**하나. 판 위에 글을 더하지 않는다.** 판 위 한글은 창에 따라 5.4px 까지
줄어든다([BOARD_TEXT](BOARD_TEXT_2026_08_22.md)). 그래서 기믹 아이콘은
«판에 실제로 그려지는 모양 그대로»를 16px 로 줄인 것이다 — 같은 그림이
두 번 나오므로 이름을 못 읽어도 짝이 지어진다.

**둘. 난수를 쓰지 않는다.** 봇 하니스가 「난수는 aimSigma 한 곳」이라는
전제 위에 있다. 대사 고르기는 사건 횟수를 센 회전이라 같은 판을 두 번
돌리면 같은 순서로 말한다.

**셋. 능력이 곧 성격이다.** 여덟이 같은 말을 하면 이름표만 바뀐다. 근접
베기는 앞으로 나가고(샛별 「앞은 내가 연다」), 거리 저격은 거리를 재고
(미리내 「거리, 좋아」), 마지막 모사는 뒤에서 본다(그믐 「본 대로 따라
한다」).

## 2. 반영하지 «않은» 것 — 값을 정해야 하는 일

여기부터는 결정이 필요해서 멈춘 자리다.

### 2-1. 난이도 균형 — 어느 가족이 바닥을 막는가

기믹을 켠 뒤 다시 쟀더니 바닥이 처음으로 갈렸다. 다만 갈린 자리가 한쪽에
몰려 있다.

| 가족                    | 바닥 정책에 대한 효과           |
| ----------------------- | ------------------------------- |
| 껍질                    | **막는다** — 피해를 먹는다      |
| 흐린 여울 · 포효 · 방벽 | 약하게 막는다 (실행마다 흔들림) |
| 반사 벽 · 잔재          | 못 막는다 — 경로만 바꾼다       |
| 가속 발판               | **오히려 쉽게 만든다**          |

여기서 규칙 하나가 나온다: **피해를 «먹는» 것만이 바닥을 막는다. 경로를
바꾸는 것은 못 막는다.**

**결정 요청.** 가속(시위) 가족을 어떻게 할 것인가.

- 난이도 축으로 쓰려면 값이 훨씬 커야 한다 — 흐린 여울을 붙여 봤지만
  100% 그대로였다.
- 아니면 시위를 «선택지» 가족으로 두고 난이도는 껍질 계열에서만 만든다.

눈감고 숫자를 굴리는 것은 이 저장소가 스스로 금지한 규칙이라 여기서
멈췄다.

### 2-2. 유성 수를 판마다 다르게 할 것인가

지금은 구조적으로 불가능하다 — 어떤 스테이지도 샷 수를 들고 있지 않다.
기믹 «전»에 정할지 «후»에 정할지가 결정이다. 모든 가족과 곱해지는 축이라
값이 크다.

### 2-3. 판 위 한글의 하한

[BOARD_TEXT](BOARD_TEXT_2026_08_22.md)의 결정이 아직 열려 있다. 이번에
아이콘을 넣은 것은 그 결정을 «우회»한 것이지 푼 것이 아니다 — 기믹 범례는
아이콘이 뜻을 지므로 글자가 작아도 견디지만, 별지기 이름표(4308회 그려지고
5.7px)는 여전히 글자에만 기대고 있다.

## 3. 반영하지 «않은» 것 — 그림이 필요한 일

### 3-1. 라이브러리에 잠든 자산

`assets/library/` 에 그림이 있는데 코드에서 한 번도 안 쓰이는 폴더가 셋이다.

| 폴더        | 장수 | 코드 참조 |
| ----------- | ---- | --------- |
| icons       | 8    | **0곳**   |
| enemies     | 11   | **0곳**   |
| skills      | 8    | **0곳**   |
| backgrounds | 2    | **0곳**   |

특히 `fx/` 14장 중 실제로 쓰이는 것은 극히 일부다. 이름만 봐도 이번에
만든 것들과 짝이 맞는 것이 있다 — `wall-shockwave.png`(반사 벽),
`pulse-wave.png`(포효), `guard-flash.png`(껍질), `homing-lock.png`·
`relay-beam.png`(겨눔). 지금은 전부 캔버스로 그렸다.

**결정 요청.** 캔버스 그림을 이 자산들로 «바꿀» 것인가, 아니면 자산을
정리할 것인가. 섞어 두면 같은 사건이 판마다 다르게 보인다.

### 3-2. 까마귀자리의 관측점

제안서의 가족 3은 유성이 표석을 때리면 그 자리에 별빛이 심기는 것이다 —
**메뉴를 넓히는 유일한 가족**이라 설계상 중요하다. 지금은 넣지 못했다.

- 배선 이유: `bumpers` 가 `buildCampaignStages` 에서 `bumpers: []` 로
  못박혀 있어 캠페인 데이터로 못 들어간다(한 줄 문제).
- 그림 이유: 지금 범퍼 그림이 동심원 셋이라 «공명 범퍼»로 읽힌다.
  관측점은 다른 물건이므로 픽션이 어긋난다.

그래서 3-x 는 임시로 «잔재(adds)»를 넣어 뒀다. 원안이 아니다.

### 3-3. 여린 핵(위력 상한)

제안서의 가족 4 원안은 「위력이 너무 세면 핵을 스치고 지나간다」인데,
그것을 `applyBossHit` 에 넣으면 안 된다는 것을 확인했다 — 호출처가 12곳
이고 별자리 캐스트는 유성보다 «먼저» 해결되므로 지난 샷의 위력으로
판정된다. 유성 직격 지점에서 따로 판정하거나 피해원 태그를 12곳에
통과시켜야 하는데, 어느 쪽도 작은 변경이 아니다.

그래서 4-x 는 임시로 «껍질»만 넣었다. 결과적으로 바닥을 가장 잘 막는
가족이 됐지만, 원안의 「넓게 벌리면 세지는데 이 판에서 세면 통하지
않는다」는 아직 없다.

## 4. 연출 — 아직 손대지 않은 자리

여기는 «있는데 약한» 것들이다. 전부 실기로 보고 적는다.

### 4-1. 정산 화면을 덮는 것들

- **업적 토스트가 결과 카드의 키커를 2.6초간 덮는다.** 스스로 사라지므로
  영구 가림은 아니지만, 카드 제목을 첫 2.6초 동안 못 읽는다.
- **루나 말풍선이 정산 위에 6초쯤 남는다.** 전투 코칭이 결과 화면에
  겹친다.

어디로 옮길지는 배치 설계라 남겼다.

### 4-2. 소환 후보 목록이 낡는다

방금 뽑은 별지기가 「별빛 속에서 대기」로 계속 남는다. 후보 구역만 다시
그리는 함수가 없고, 화면 전체를 다시 그리면 플레이어가 보고 있는 리빌을
지운다.

### 4-3. 기믹 연출 중 아직 밋밋한 것

이번에 가속·흐림에 방향을 줬지만 나머지는 기본형이다.

- **잔재(adds)가 죽을 때** — 지금은 일반 폭발이다. 「떨어진다」가 없다.
- **포효** — 화면 흔들림과 파형은 있는데, 별지기가 «밀려나는 동안» 궤적이
  안 남는다. 순간이동으로 읽힐 여지가 있다(제안서 §8-3이 짚은 자리와
  같은 뿌리다).
- **껍질이 깨지는 순간** — 소리는 갈랐지만(shieldBreak) 그림은 그대로다.
  판이 열리는 가장 큰 순간인데 화면이 조용하다.
- **도는 방벽** — 이번에 돌게 만들었지만 «틈»이 어디인지 그림으로 안
  보인다. 타이밍을 재라고 해 놓고 잴 것을 안 보여 준다.

### 4-4. 온보딩이 기믹을 «보여 주지»는 않는다

루나가 한 줄 말하지만, 1-1 수업이 조준을 가르칠 때 쓴 «암전 + 손가락»
같은 시범은 없다. 기믹은 판마다 다르므로 수업을 여덟 벌 만들 수는 없다 —
대신 첫 만남에서 그 물건 하나만 잠깐 밝히는 정도는 가능하다.

**결정 요청.** 첫 만남에 시범을 넣을 것인가, 말 한 줄로 둘 것인가.

## 5. 무엇부터 하면 좋은가 (권고, 결정 아님)

1. **2-1의 균형 결정** — 다른 모든 값이 여기에 딸려 온다.
2. **3-1의 자산 결정** — 캔버스로 갈지 그림으로 갈지 정해야 연출 작업이
   두 번 안 된다.
3. **4-3의 연출** — 특히 껍질 깨짐. 판이 열리는 순간이 조용한 것이 지금
   가장 큰 구멍이다.
4. 3-2·3-3의 원안 복원은 위 셋이 정해진 뒤에.
