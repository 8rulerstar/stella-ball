# Prism Breakers Bot Harness

`node bot/run-bot.mjs > bot/latest-report.json`으로 실행한다. 이 하니스는 DOM·canvas·이미지 API 없이 3개 고정 스테이지, 8명 로스터의 모든 3인 조합을 4발 기준으로 반복 실행한다.

검증 대상은 보스 체력, 4발 제한, 벽 반사, 룬 충돌, 몸체/약점 피해, 룬별 직접 피해다. 결과에는 클리어율, 평균 잔여 체력, 평균 룬 충돌, 실패한 스테이지·파티가 남는다.

브라우저 전투와 같은 수치를 사용하는 균형 모델이며, 렌더링과 입력은 의도적으로 포함하지 않는다. 능력 수치나 스테이지 좌표를 바꾸면 배포 전 이 명령을 다시 실행해 `bot/latest-report.json`을 갱신한다.
