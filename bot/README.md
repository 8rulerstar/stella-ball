# Prism Breakers Bot Harness

`node bot/run-bot.mjs > bot/latest-report.json`으로 실행한다. 이 하니스는 DOM·canvas·이미지 API 없이 과거 3개 고정 스테이지, 과거 8명 로스터의 모든 3인 조합을 4발 기준으로 반복 실행한다.

> 현재 상태: 이 하니스는 **당겨 쏘는 가로 반사 모델의 이전 검증 기록**이다. 현재 브라우저 전투는 8인·기본 5발·이동 별지기·분열체·별자리 배율·`1-2` 공명 범퍼를 사용하는 탑다운 당구형이다. 따라서 이 하니스와 기존 `latest-report.json`은 현재 밸런스 판정이나 제출 수치에 사용하지 않는다.

검증 대상은 보스 체력, 4발 제한, 벽 반사, 룬 충돌, 몸체/약점 피해, 룬별 직접 피해다. 결과에는 클리어율, 평균 잔여 체력, 평균 룬 충돌, 실패한 스테이지·파티가 남는다.

다음 갱신에서는 브라우저 런타임과 같은 8인 로스터(리아 포함), 5발, 이동 별지기 충돌, 루미 분열체, 약점, 별자리 배율, 정산 공격, 리아 이동 피해, 1-2 범퍼를 결정론적으로 모델링한다. 그 전까지 명령 실행은 레거시 하니스 회귀 확인에만 사용한다.
